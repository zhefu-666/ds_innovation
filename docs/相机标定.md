# 相机标定

统一操作顺序：内参采样与计算 → 固定相机和标定板 → 外参及地面映射 → 独立检查点验收 → 部署配置。当前推荐使用 9×6 对称圆点板，物理尺寸必须实测；拍摄分辨率与实际运行模式保持一致。

内参网页与外参计算是互补步骤，不应把内参通过等同于完整地面几何验收。相机位置、焦距或分辨率改变后需要重新检查对应标定。工具参数参考保留在 `tools/camera_calibration/README.md`。

下列操作资料合并保留；旧 IP 地址是当时示例，访问时使用板卡当前地址。本轮不改变现有相机发送代码或标定文件。

python3 tools/camera_calibration/guided.py --stop-preview

#### 4. 平板显示与量尺

### 4.1 使用的图案

2026-09-29 起使用新购的 9×6 对称圆点标定板，旧的 10×7 平板图案不再使用。

| 项目 | 数值 |
|---|---|
| 图案类型 | 对称圆点板 |
| 圆点数量 | 横向 9 列、纵向 6 行，共 54 点 |
| 相邻圆心间距 | 以尺量为准 |

程序按 9×6 圆点定位；现场使用实物标定板时，将有 9 个圆点的方向横放在画面中。拍摄前核对整板均在画面内。

没有实体板时，网页 PDF 地址提供备用 9×6 图案：原图间距 12 mm、圆直径 5 mm、页面 200×150 mm。**平板显示出来的实际尺寸以尺量为准。**

### 4.2 显示设置

使用实体标定板时，保持板面平整、无反光，跳过第 2 条中的平板设置。

1. 平板横屏显示整张 PDF，确保 54 个圆点完整可见。
2. 调整到合适大小后，锁定缩放和屏幕方向；关闭自动息屏、自动亮度和夜间色温。
3. 避免灯光反射到圆点上。观察相机画面，若出现条纹、明显摩尔纹或过曝，先调整亮度、曝光或距离。
4. 固定相机焦点。不能在采集中自动改变焦点、变焦、分辨率或裁剪方式；程序不会替你强制关闭所有型号相机的自动对焦。

### 4.3 只需量两条长度

| 网页字段 | 尺子量哪里 | 计算方式 |
|---|---|---|
| 横向第 1 到第 9 个圆心跨度 / mm | 同一行最左圆心到最右圆心 | 总跨度 ÷ 8 |
| 纵向第 1 到第 6 个圆心跨度 / mm | 同一列最上圆心到最下圆心 | 总跨度 ÷ 5 |

量圆心不方便时，可以量两个圆的**同侧边缘**，例如左侧第一个圆的左边缘，到最右圆的左边缘。不要量两端圆的最外侧总宽，也不要量平板边框。

举例：若实测横向 144 mm、纵向 90 mm，则间距都是 18 mm。网页填 `144` 和 `90`，不用自己把间距填进代码。

两方向算出的间距相差超过 1%，程序会拒绝开始，需检查量尺位置或图案是否被拉伸。

填写后勾选确认框，点击“开始相机与分步拍摄”。**从此直到 25 张拍完，不要再缩放 PDF。** 如果缩放发生变化，重新开始一整轮。

#### 5. Foxglove 怎么连接

Foxglove 是可选观看界面；只用网页也能完成标定。

1. 选择 **Open connection → Foxglove WebSocket**。
2. 地址填写 `ws://192.168.1.123:8766`，连接。
3. 按下表添加面板。

| 面板类型 | 话题 | 看什么 |
|---|---|---|
| Image | `/calibration/image` | 流畅的相机实时画面；圆心连线在网页检测快照中显示 |
| Raw Messages | `/calibration/status` | `count` 已拍数量、`step` 当前提示、`detected` 是否识别完整、`ready` 是否可拍 |
| Raw Messages | `/calibration/result` | 完成后的矩阵、畸变、fx/fy/cx/cy 和误差 |

暂时不想填写尺寸时，先在网页点击“打开相机，仅预览 / Foxglove 观看”。这不会创建标定会话或保存照片。

Foxglove 图像目标 30 Hz，默认预览尺寸 960×540；保存的标定原图仍然是 **1280×720**。网页与 Foxglove 共用同一次相机采集。

填写尺寸、拍摄、撤销仍在网页操作。未完成标定时 `/calibration/result` 的 `available` 为 `false`；完成后才变为 `true`。

相机停止时 Foxglove 可能保留最后一帧。请同时看 `/calibration/status.camera_fresh`，为 `false` 就不是正在更新的画面。

#### 6. 按顺序拍摄 25 张

每一步都按以下操作：**摆好平板 → 停稳约 2 秒 → 确认圆点完整且清晰 → 点击“拍摄并保存这一张”**。

成功后页面计数增加 1，再移动到下一姿态。点击失败不会跳步，按提示调整后重试。

| 照片编号 | 摆放方式 |
|---|---|
| 1 | 中央，正对相机，中等距离 |
| 2～9 | 依次覆盖左上、上中、右上、右中、右下、下中、左下、左中 |
| 10 | 中央靠近，圆点阵列占画面宽度约 60%～80% |
| 11 | 中央稍远，圆点阵列占画面宽度约 30%～40% |
| 12～15 | 中央，依次让左边、右边、上边、下边靠近相机，倾斜约 20° |
| 16～19 | 分别偏左、偏右、偏上、偏下，对应方向倾斜约 35° |
| 20 | 左上区域，同时向左右、上下方向倾斜 |
| 21 | 右下区域，换一个组合倾斜姿态 |
| 22 | 中央，平板自身平面内旋转约 20°，再稍微倾斜 |
| 23 | 独立验证：偏左、稍近，换一个倾斜姿态 |
| 24 | 独立验证：偏右、稍远，换一个倾斜姿态 |
| 25 | 独立验证：中央，同时向两个方向倾斜 |

完整 54 个圆点和白边应始终在画面里。程序检查完整识别、清晰度、大小和重复姿态，但不会代替你判断所有倾斜角度；请按网页提示摆放，不能一直正对相机。

拍错时点“撤销上一张”，然后重拍。撤销照片会归档，不直接删除。第 25 张成功后自动开始计算，此时不能再撤销。

第 1～22 张用于拟合内参，第 23～25 张只做独立照片验证。计算完成后相机自动释放，网页与 Foxglove 仍可查看结果。

#### 7. 照片保存在哪里

**不需要截图，不需要手机拍照，也不用手动另存。** 网页按钮保存的是上位机摄像头的原始分辨率图像，用无损 PNG 编码，不含圆心连线。

页面会显示本轮目录，类似：

```text
/home/cat/ds_innovation/calibration_runs/circles_日期_时间_随机编号/
├── session.json          测量值、分辨率、拍摄进度
├── samples/
│   ├── 001.png           第一张原图
│   └── 025.png           第 25 张原图
├── detected/             带圆心连线的检查图，不用于计算
├── 001.json … 025.json   各张照片对应的提示与圆心坐标
├── retakes/              如有撤销，旧照片在这里
├── intrinsics.yaml      内参和畸变参数，完成计算后生成
├── report.json          拟合及验证误差、覆盖情况、警告
└── 使用说明.txt         本轮参数和接入位置说明
```

每轮会建立新目录，不覆盖上一轮。网页刷新不会丢失仍在运行的会话；**退出进程、断电或重启后，不支持接着拍半轮**，需重新完整拍摄。已保存照片保留。

完成后页面可下载 YAML、误差报告和接入说明。如果要把整轮原图也复制到电脑，在**电脑终端**执行下面命令，把 `实际会话目录名` 替换为页面显示的目录名：

```bash
scp -r cat@192.168.1.123:/home/cat/ds_innovation/calibration_runs/实际会话目录名 ./
```

#### 8. 如何看结果，参数填哪里

| 输出字段 | 含义 |
|---|---|
| `camera_matrix` | 3×3 内参矩阵，包含 fx、fy、cx、cy，单位像素 |
| `dist_coeffs` | 畸变系数，顺序为 k1、k2、p1、p2、k3 |
| `image_width` / `image_height` | 参数对应的图像分辨率 |
| `fit_rms_px`，位于报告中 | 前 22 张的拟合重投影误差 |
| `holdout_rms_px`，位于报告中 | 后 3 张独立照片的重投影误差 |

建议拟合 RMS 小于 0.5 像素，单张拟合与独立验证误差小于 1 像素。出现警告时，结果仍会保存供检查，但应先排查后重拍。低误差不能替代去畸变画面检查与真实地面测量。

**无需手抄数字或自己编辑矩阵。** 程序已经按 OpenCV YAML 格式保存到本轮的 `intrinsics.yaml`。

填写位置：一体化外参标定通过后，把生成的完整 `camera.yaml` 放到 `/home/cat/ds_innovation/config/camera.yaml`。`/home/cat/ds_innovation/config/rescue.yaml` 对应字段为：

```yaml
calibration_file: ./config/camera.yaml
```

当前 `CameraCalibration::valid()` 要求完整文件包含 `ground_homography`，所以只有内参的 `intrinsics.yaml` 不能直接替代完整 `camera.yaml`。当前主程序尚未加载 `rescue.yaml`，填写此路径不会立即启用测距，后续还要接通加载与图像尺寸检查。

#### 10. 退出、重拍与恢复原项目

### 自己在 SSH 前台启动的程序

回到运行标定的 SSH 终端，按 **Ctrl+C**。结果不会删除。

需要重拍时，再执行第 3 节的启动命令。重新确认平板显示尺寸和焦点，新的一轮会存到新目录。

### 已由助手在后台启动的程序

如果网页已经能访问，直接使用即可。若要结束或重启，先确认当前没有需要继续的拍摄，再在远程终端查看进程：

```bash

```

找到运行 `guided.py` 的那一行，最前面的数字是 PID。执行 `kill -INT PID`，将 `PID` 换成实际数字；不要误停 `rescue_upper_host` 或其他进程。等待原网页服务退出后，再执行启动命令。

先退出标定程序，确保相机已经释放，然后在远程终端执行：

  --imu --imu-port /dev/ttyUSB0 --imu-baud 115200

#### 11. 后续：使用圆点棋盘完成一体化外参标定

内参合格后，不再单独执行 `calibrate.py ground`。请按照[相机圆点棋盘一体化标定操作指南](相机标定.md)，使用 9×6 圆点板完成外参、地面单应矩阵和独立地面点验收。

外参命令使用：

```bash
python3 tools/camera_calibration/calibrate.py extrinsics \
  --pattern circles --cols 9 --rows 6 \
  --intrinsics /home/cat/ds_innovation/calibration_runs/实际会话目录名/intrinsics.yaml \
  --image /home/cat/ds_innovation/calibration_runs/ground_board.png \
  --square-mm 实际圆心间距 \
  --origin-x 实测值 --origin-y 实测值 \
  --yaw-deg 实测值 --board-height-mm 实测值 \
  --confirm-order --check-points extrinsics_checks.json \
  --max-rms 0.5 --max-error-mm 20 \
  --camera-pitch-cdeg 拍照时舵机读回值 \
  --output calibration_runs/extrinsics_circles_validated_01
```

`--camera-pitch-cdeg` 填拍照时相机舵机的读回 pitch（0.01°，正值向下），详见一体化指南和标定工具 README。
若 0 号圆点位于远端左侧、0→1 向机器人右侧而 0→9 朝机器人后方，命令还须加入 `--reverse-board-y`；其他摆放方向请按一体化指南核对编号图。

只有 `extrinsics.json` 中 `validated` 为 `true` 并生成正式 `camera.yaml` 后，才部署到 `config/camera.yaml`。

#### 12. 常见问题

| 现象 | 处理 |
|---|---|
| 网页打不开 | 检查电脑和平板网络、上位机地址及 SSH 中程序是否运行；重启上位机后需要重新启动服务 |
| 显示“标定程序已经在运行” | 正常提示，直接打开网页；本次没有启动第二份程序，也没有改动现有会话 |
| 显示端口占用或旧版本的 `Address already in use` | 已有进程占用 8081 或 8766；先确认现有服务，确需重启时按第 10 节处理，不要结束无关进程 |
| 无法打开相机 | 检查 USB 连接与 `/dev/video0`；退出其他相机软件，使用带 `--stop-preview` 的启动命令 |
| 画面出现，但不能拍摄 | “仅预览”不会开始标定；先填写实测尺寸并开始，再看圆点识别提示 |
| 横纵间距相差超过 1% | 检查是否量圆心/同侧边缘、是否把 8 或 5 个间隔数错、平板是否拉伸图案 |
| 识别不到全部 54 个点 | 留出白边，避免遮挡、反光、模糊与过大倾角；改变距离，检查屏幕条纹 |
| 提示姿态重复 | 改变位置、距离或倾角，不要连续拍相同画面 |
| Foxglove 已连接但没有图像 | 确认 8766 端口、Image 面板话题正确，并在网页打开“仅预览”或开始拍摄 |
| Foxglove 图像停住 | 检查 `camera_fresh`；标定完成后释放相机属于正常情况 |
| 参数误差高 | 查看 `detected` 原图复核，改善姿态覆盖、清晰度、反光、屏幕条纹，固定焦点后重拍 |
| 重新启动后进度变为 0 | 当前不恢复半轮会话；旧照片仍在旧目录，重新完整拍摄 |
| 改了相机焦点或模式 | 重新做内参标定；改变安装位置后重新做圆点棋盘一体化外参标定 |

## 相机圆点棋盘一体化标定操作指南

### 相机圆点棋盘一体化标定操作指南

本文是本项目的统一标定流程。完成后，一份 `camera.yaml` 同时包含：

- 相机内参和畸变参数；
- 相机相对机器人底盘的外参；
- 地面单应矩阵 `ground_homography`；
- 独立地面点验收结果。

使用本流程时，不需要再单独执行 `calibrate.py ground`。

#### 1. 需要准备的设备

- 新购 9×6 对称圆点板（横向 9 列、纵向 6 行，共 54 个圆点）；
- 固定安装的相机；
- 毫米刻度尺；
- 直角尺或量角器；
- 一块平整、坚硬的垫板，用来保持圆点板平整；
- 至少 3 个独立地面检查标记。

当前圆点板外参模式使用：

```text
--pattern circles --cols 9 --rows 6
```

`--cols` 是横向圆点数，`--rows` 是纵向圆点数，不能对调；标定板竖放时，以相机画面中的横向为准。

`--square-mm` 填的是**相邻圆心之间的距离**，不是圆的直径。旧 10×7 平板显示的 16.3889 mm 不能沿用，新标定板必须用尺重新测量。

#### 2. 先确认内参合格

内参报告应满足：

- `status` 为 `candidate_requires_validation`；
- `warnings` 为空；
- 拟合 RMS 小于 0.5 像素；
- 每张拟合图片误差小于 1 像素；
- 独立验证图片误差小于 1 像素。

当前选定的内参入口：

```text
/home/cat/ds_innovation/calibration_runs/intrinsics_current.yaml
```

该入口当前指向 `circles_20261003_045556_6bf32a/intrinsics.yaml`，由 9×6 实物圆点板的 25 张照片生成，报告已通过本节门槛。它只包含镜头内参与畸变；相机安装位置仍须做外参标定。

以后重新标定内参时，先审核新会话的 `report.json`，确认合格且分辨率、焦点、镜头模式与实车一致，再在上位机切换入口并核对目标：

```bash
cd /home/cat/ds_innovation
ln -sfn circles_新会话目录/intrinsics.yaml calibration_runs/intrinsics_current.yaml
readlink -f calibration_runs/intrinsics_current.yaml
```

上述目录名必须替换为实际的新会话目录。外参命令通过 `--intrinsics` 显式读取该入口；切换内参不会自动重算已有的外参结果。

#### 3. 固定相机和圆点板

相机必须已经安装在最终使用位置，并保持：

- 图像分辨率为 1280×720；
- 焦点和镜头模式不变；
- 支架不晃动；
- 标定过程中不移动相机。

将圆点板平放在实际地面上，并用硬板固定。圆点板必须水平，不能手持倾斜进行机器人外参标定。

在圆点板外放置至少 3 个独立地面检查点，建议分布在近处、远处和左右不同位置。检查点不能使用圆点板上的圆心。

#### 4. 测量外参参数

机器人坐标约定：

- 原点：底盘中心在地面的投影；
- x 轴：向右为正；
- y 轴：向前为正；
- z 轴：向上为正；
- 单位：米。

### 4.1 测量 `square-mm`

用尺测量连续多个圆心之间的总长度，再除以圆心间隔数量。例如测量第 1 到第 9 个圆心的总长度，应除以 8：

```text
square-mm = 横向总跨度 / 8
```

也可以测量纵向第 1 到第 6 个圆心，再除以 5。横纵结果相差应尽量小于 1%。

### 4.2 确定第 0 个圆点

程序使用圆点阵列左上角的第一个圆心作为编号 0：

- `0 -> 1` 是棋盘 `+X` 方向；
- `0 -> 9` 是棋盘 `+Y` 方向；
- 对 9×6 圆点板，编号 9 是第二行第一个圆点，即第 0 个圆点正下方的那个。

运行后必须检查 `corners_numbered.png`，确认程序编号与实际测量的第 0 个圆点一致。如果方向相反，使用 `--flip-cols` 或 `--flip-rows`，并重新测量对应原点坐标。
若 0 号在画面远端左侧，0→1 向机器人右方，而 0→9 朝机器人后方，则不需要翻转编号，但必须在外参命令中加入 `--reverse-board-y`。该选项同时使棋盘坐标的 +Z 朝下，保持三维变换为合法旋转。

### 4.3 测量 `origin-x` 和 `origin-y`

在地面标出底盘中心的投影点，测量它到第 0 个圆点的坐标：

- 第 0 个圆点在底盘中心右侧，`origin-x` 为正；在左侧则为负；
- 第 0 个圆点在底盘中心前方，`origin-y` 为正；在后方则为负；
- 命令使用米，例如 550 mm 填 `0.55`。

测量的是第 0 个圆心，不是纸张边缘、图案边缘或圆点板中心。

### 4.4 测量 `yaw-deg`

测量圆点板 `+X` 方向相对机器人向右方向的角度：

- 圆点板 `+X` 正好指向机器人右侧：`yaw-deg 0`；
- `+X` 从右侧转向前方：角度为正；
- `+X` 指向机器人前方：约 `90` 度。

可以先用直角尺将机器人右方向延长到地面，再用量角器测量；也可以把圆点板与地面标线对齐后填 0 度。
`yaw-deg` 只描述 0→1 的方向。0→9 若朝机器人后方，仍可使用 `yaw-deg 0`，但须同时添加 `--reverse-board-y`。

### 4.5 测量 `board-height-mm`

测量圆点板印刷表面相对地面的高度：

- 纸直接铺在地面上，填实际纸张厚度或近似 0；
- 纸贴在 4 mm 硬板上，填约 4；
- 有垫片、玻璃或外壳时，将这些厚度一起测量。

如果只是相机在固定支架上重新放回同一位置，应重新检查独立地面点，不要直接假设旧结果仍然有效。

拟合 RMS 希望小于 0.5 px，单张和独立验证误差希望小于 1 px。警告时保留候选文件供排查，建议重拍；不会覆盖生效配置，也不会将候选称作实测验收通过。
低 RMS 不能排除平板反光、摩尔纹、姿态退化或参数不稳定，后续应检查去畸变画面与实测地面距离。

1. 内参报告合格后，按项目根目录的《相机圆点棋盘一体化标定操作指南》执行 `calibrate.py extrinsics --pattern circles`，一次完成外参、地面单应矩阵和独立地面点验收；不需要再单独执行 `calibrate.py ground`。
2. `intrinsics.yaml` 只有 `camera_matrix`、`dist_coeffs` 和尺寸等字段，**不要直接改名为完整 camera.yaml**。项目 `CameraCalibration::valid()` 还要求 `ground_homography`。
3. 地面标定并通过独立测量验收后，完整输出文件部署到 `/home/cat/ds_innovation/config/camera.yaml`。
4. `/home/cat/ds_innovation/config/rescue.yaml` 中对应位置是 `calibration_file: ./config/camera.yaml`。目前主程序尚未读取该 YAML，后续还需要接入加载和尺寸检查；当前填写路径不会自动启用距离计算。
5. `calibrate.py extrinsics` 支持方格棋盘和本工具使用的 9×6 对称圆点板。使用圆点板时增加 `--pattern circles --cols 9 --rows 6`，并填写实际圆心间距；仍需提供独立地面检查点并确认 `corners_numbered.png` 的方向。

#### 2026-09-27 预览提速更新

启动命令不变。采集、视频预览与圆点检测分别运行，网页使用连续 MJPEG 视频流，不再每 700 ms 换一张图片。
默认请求相机 60 FPS、预览和 Foxglove 目标 30 FPS、检测上限 10 FPS；实际速度由曝光、USB、算力和网络决定。
本机首次实测采集约 30 FPS、预览约 30 FPS、Foxglove 接收约 25 FPS、圆点检测约 3 FPS。页面分别显示三种实测帧率。

实时预览显示原始画面，圆心连线在网页另一个“检测快照”中显示，避免把旧检测结果画到更新的视频帧上。
点击拍摄保存的是检测快照对应的 1280×720 原图和圆心坐标。检测结果超过 1 秒禁止拍摄，请停稳等待新检测。
算法仍使用原图分辨率的圆心；没有通过缩小标定原图来提速。背景过于杂乱、候选圆点过多时会拒绝匹配，请让完整圆点板占据画面主要区域。

可在启动时设置速度：

```bash
python3 tools/camera_calibration/guided.py --stop-preview \
  --camera-fps 60 --preview-fps 30 --detect-fps 10
```

现有服务运行时新参数不会自动生效；需要退出旧进程后重启。更新后刷新标定网页；Foxglove 如未自动恢复，请重新连接 8766，图像话题仍为 `/calibration/image`。
