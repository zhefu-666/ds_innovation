# 遥测与查看

## 主程序遥测

`tools/remote_camera_telemetry/project_bridge.py` 读取主程序产生的遥测快照，自身不打开摄像头或控制串口。HTTP 默认8080，Foxglove WebSocket默认8765。访问地址使用当前板卡地址，不依赖历史固定IP。

页面 `/status` 提供状态，`/stream.mjpg` 提供带标注图像。Foxglove 可订阅 `/camera/image`、`/detections`、`/fsm/state`、`/decision/live`、`/runtime/config` 和健康通道。

计算速度、已发送命令和实测速度必须区分；状态过期、生产者缺失或 `valid=false` 不能当作实时有效数据。网页或WebSocket可连接不代表主程序正在发布图像。

正式比赛入口已有遥测桥复用/启动逻辑；不要为查看重复启动主程序。`manage_project.py` 属于另一套预览管理入口，历史默认构建路径已清理，不在此提供未经核对的启动命令。

## 独立相机模式

`tools/remote_camera_telemetry/server.py` 是独立相机工具，与主程序遥测不同，会打开摄像头。不得与主程序争用相机及8080/8765端口。独立相机模式不提供机器人任务闭环。

## 板上与演示查看

`tools/board_monitor/monitor.py` 在板卡本机18080端口显示已有遥测和比赛日志，不打开相机、不操作串口。

`tool/demo/` 的查看与演示使用独立运行副本，部分入口使用18765；它不是正式比赛构建。分别查阅工具目录README。

## 开发与验证

主程序遥测发布器为 `src/telemetry_publisher.cpp`，桥接实现为 `tools/remote_camera_telemetry/project_bridge.py`。已有软件测试和验证脚本保留原位。CPU负载、图像新鲜度、数据有效性和实际发布能力须分别判断，不以历史记录代替当前测量。
