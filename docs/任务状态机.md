# 任务状态机

当前任务实现以 `src/push_task.cpp`、`include/rescue/push_task.hpp` 及对应测试为准。校赛源码已收拢，本次不改变状态机。

主要职责包括搜索与目标选择、接近与机构动作、捕获确认、寻找己方区域、搬运和投放、脱离与结果核验。目标锁定、观测有效性、机构反馈、颜色规则及各阶段时限共同决定能否转移状态。

首批物资、颜色优先级、伤员单独运输等规则存在不同阶段的调整；具体条件以当前实现及启动配置为准。不能把早期调参记录中的速度、距离和超时直接当作当前默认值。

相机与A6当前协议见通信协议文档。开闭反馈是持续状态，不能代替视觉捕获或交付证据。软件通过、日志中的 assumed 结果和完整实车验收应区分。

历史行为变化和阶段记录集中在历史文档；重构应保留现有回归测试，并在实际改变规则时同步修改本说明。
