## 当前入口与资源

正式比赛入口为 `tools/match/match_main.sh`，默认二进制为 `build-release/rescue_upper_host`，允许 `RESCUE_BINARY` 显式覆盖；脚本会在任何设备动作之前打印实际路径、md5 与构建时间。脚本默认检查配置，硬件执行需要明确的运行参数与现场条件；执行前阅读脚本参数，不把配置检查当作运行许可。

当前脚本使用 `models/detect_fp.rknn`、`models/zone_pose_fp.rknn`、`benchmark_results/librknnrt.so`、`config/camera.mechanical_5_40.yaml`、`config/zone_geometry.json`、`config/zone_color.field.json` 和 `config/frame_20261008.assume.json`。模型和运行库需要单独准备，部分标定配置仍包含假设。

辅助入口 `start_capture_scan.sh`、`start_controlled_empty_field.sh`、`start_hardware_blue.sh` 与正式比赛入口统一使用 `build-release/rescue_upper_host`，仅运行参数不同。`tools/demo` 是独立演示入口，使用 profile 指定的二进制，不与正式比赛入口共用运行配置。
