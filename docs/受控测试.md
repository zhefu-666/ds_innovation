# 受控测试

受控空场、旋转搜索和放宽通道检查是专用测试模式，不作为通用运行许可。相关入口位于 `tools/match/`，默认配置检查与显式硬件执行须区分。

`--controlled-ignore-clearance` 放宽路径检查，并不证明现场无障碍。该模式的适用条件、剩余健康约束、停止机制及现场人员隔离应在每次实机测试前确认。不得通过修改验收字段伪造实测证据。

部分旧辅助脚本仍指向保留的 `build-camera-offset-20261007` 构建。正式校赛构建使用 `build-school-competition`。本次没有启动这些测试或操作设备。

过去测试中的具体参数与软件修复经过见历史记录，不能直接作为本轮测试参数。相机发送实现按用户要求保持现状。
