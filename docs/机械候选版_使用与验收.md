# 机械接入候选版

本目录为独立候选，不替换 `/home/cat/ds_innovation` 的源码、二进制、配置或启动脚本。

## 实现入口

- `src/main.cpp` 实际调用 `PixelSelector`，在物料规则允许的集合内按占比选择；连续3帧确认，平滑系数0.5，挑战目标超过1.20倍并持续3帧后切换。已进入接近事务时，候选切换会使旧目标跟踪失配并停车重识别，不会边行驶边无确认换目标。切档或统计模式改变后重新确认3帧。禁止物和未知物仍保留在检测集合供通道阻挡判定。
- 原图 `CV_8UC1` 实例掩码统计非零像素；没有掩码时标记 `box_area`。不猜测低分辨率或局部掩码的映射，不混合比较两种模式。本次检查的检测推理路径没有输出实例掩码。`box_area_accepted=0` 时框模式不能提供可执行目标。
- `FrameAction::Open` → 0°；`Close` → 20°。15字节TX、8字节A6及CRC布局不变。A6的原始0/1意义必须由已验收配置提供。角度不是反馈状态。
- `MotionCommand::frame_transaction` 表示逻辑事务，同一事务重发不换编号，显式重试通过新事务号换编号。编号1..255循环；动作反馈须新鲜、晚于事务创建、编号与配置期望状态均匹配。
- `MultiViewCapture` 管理独立观察轮次：至少两档，每档5个独立新鲜帧；每档2秒（包括稳定及取证），全轮8秒，最多3档。闭合状态、动作编号、车体静止证据改变则作废。
- 框边采用各档独立凸多边形。框截断、相交、未知/禁止物、低置信度、缺失地面接触或空间位置、关联不唯一均保持无法确认。空间关联阈值当前0.025m、边界余量6px，属于待现场标注验收的调试初值。
- 跨档按类别和有效车体地面坐标作一对一关联，不依赖相同track_id，不累加视角计数。同类多目标距离过近会被保守拒绝。第三档保留前两档冲突，不通过多数投票掩盖冲突。
- 新状态机只有多档确认且库存符合物料规则才进入CARRY；未知或超时保持20°关并SAFE_STOP。无打开反馈不倒退。通信/安全证据异常停车后不自动以相反动作恢复。
- 新schema 2配置启用0.10m/s速度上限、单轮60秒、捕获前累计前向指令积分0.30m、累计后退积分0.20m；更换目标不会重置预算。指令积分是上限保护，不能替代实测里程或制动距离。
- 遥测包含像素模式/原始与平滑占比、观察轮次/档位/帧数/结论/原因；网页明确显示检测框占比和三态结果。

## 配置与启动限制

独立配置：`config/frame_20261007.pending.json`。已录入尺寸及来源；近/远内沿尚未假定为已确认坐标变换。181.07mm前向外沿是推导值。相机档位、多边形、A6映射、停车条件、开口扫掠空间、实车验收均未填写为通过。

加载器拒绝未验收配置；旧schema 1仅保留回归/检查能力，不能授权新候选硬件运行。不要直接把测试中的合成配置或布尔值复制到运行配置。

多档观察额外要求新鲜非预测的区域位姿，且整轮位置变化小于0.01m、方向变化小于0.02rad。无此证据即无法确认。当前相机观察档位可能看不到区域，需现场验证共同可观测条件；不能把零速度指令当作静止测量。缺少地面几何时也不能确认多物关联。本候选没有用外观模型猜测完全遮挡目标。

软件检查（不打开串口）：

```bash
cd /home/cat/ds_innovation_candidates/mechanical-20261007
cmake -S source -B build-candidate -DCMAKE_BUILD_TYPE=Release -DRESCUE_ENABLE_TELEMETRY=ON
cmake --build build-candidate -j 3
ctest --test-dir build-candidate --output-on-failure
build-candidate/rescue_upper_host --check-config --task-calibration source/config/frame_20261007.pending.json
```

最后一个命令预期拒绝待标定配置，不能将拒绝当作构建失败。

工具：`tools/frame/frame_ctl.py open|close --frame-config 已验收配置 --dry-run` 为只读反馈及预览；`status` 不要求动作映射。兼容gripper入口转发同一工具。相机工具也要求同一映射并保持反馈状态，取消隐式先开框。`send_velocity.py` 在此候选中仅用于编码预览，原来的任意角度/调用者自填编号发送入口被禁用。

静止20次开闭验收如何获得初始映射，仍须在现场人员确认机构方向、电控协议与急停后另行明确测试范围；本候选不会自动猜测映射去试动作。
