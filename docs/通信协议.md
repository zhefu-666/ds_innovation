# 通信协议

当前协议说明依据用户 2026-10-15 确认。相机发送角度为 **0–80°，40°为正常启动中位角度**；A6 持续表示开闭状态，**开为1、关为0**。

当前相机下发代码据用户反馈可正常使用，保留现有发送与角度转换实现，本轮不修改控制代码、启动角度或标定文件。本次未重新进行硬件验证。

## 上位机发送：0x56，15 字节

| 偏移 | 类型 | 内容 |
|---|---|---|
| 0 | uint8 | 帧头 0x56 |
| 1–4 | float32 | vx，m/s，正前进、负后退 |
| 5–8 | float32 | wz，rad/s |
| 9 | int8 | 方框角度命令；独立于相机角度，逻辑动作对应关系由机构配置定义 |
| 10 | uint8 | 动作编号，1–255 循环，0 保留 |
| 11–12 | int16 | 相机目标角，整数度，0–80°；40°为正常启动中位角度 |
| 13–14 | uint16 | CRC16/Modbus，低字节在前 |

小端，CRC 覆盖 0–12，初值 0xFFFF，多项式 0xA001，无最终异或。不直接发送业务对象的 sizeof 内容。

## 下位机反馈：A6，8 字节

| 偏移 | 类型 | 内容 |
|---|---|---|
| 0 | uint8 | 帧头 0xA6 |
| 1 | uint8 | 开闭状态：开过一次后持续发1，关闭后持续发0 |
| 2 | uint8 | 动作编号 |
| 3–4 | int16 | 相机反馈角，整数度，0–80° |
| 5–6 | uint16 | CRC16/Modbus，低字节在前 |
| 7 | uint8 | 帧尾 0x0A，不参与 CRC |

CRC 覆盖 0–4。按帧头、定长与 CRC 解析，不能仅按换行拆包。第二字节不是完成脉冲；确认动作须同时检查反馈新鲜度、编号与期望开闭状态。状态匹配不独立证明机械到位或物料已捕获。

## 实现与验证边界

内部字段名和内部角度单位不能直接作为线上单位。当前实现保持不变，相关兼容转换由现有代码处理。命令过期归零、退出停车和串口独占由现有发送链处理；下位机独立失联停车能力需单独确认。

A6 不含 IMU 姿态或实测底盘速度。IMU 使用独立串口和协议，见 IMU 接入说明。
